# ADS - Oxi Badminton Biên Hòa

Dự án Landing Page / Mockup Web đặt sân cầu lông trực tuyến dành cho **Sân Cầu Lông Oxi Badminton - Biên Hòa**.

## 📌 Tính năng chính
- **Mô phỏng 2 chế độ xem (Simulator):**
  - Giao diện Điện thoại (Mobile Mockup khung điện thoại 440px).
  - Giao diện Toàn màn hình (Full Responsive).
- **Bộ nhận diện thương hiệu:**
  - Tone màu Volt / Xanh Neon thể thao kết hợp nền tối Dark Mode hiện đại theo phong cách giải đấu BWF.
- **Tính năng tương tác:**
  - Lưới chọn khung giờ đặt sân & các sân thi đấu (Sân 1, Sân 2, Sân 3...).
  - Chọn ngày, tính tổng tiền tự động theo số giờ chọn.
  - Tích hợp thông tin chuyển khoản / quét mã QR thanh toán nhanh (VIB QR).
  - Khung chính sách & hotline liên hệ hỗ trợ.

## 🛠 Công nghệ sử dụng
- **HTML5 & CSS3**
- **Tailwind CSS (CDN)**
- **Google Fonts:** Montserrat & Plus Jakarta Sans

## 🚀 Hướng dẫn mở dự án
- Mở trực tiếp file `index.html` hoặc `mockup.html` trên trình duyệt web (Chrome, Edge, Cốc Cốc...).
- Hoặc mở bằng extension **Live Server** trong VS Code.
